# 콘텐츠 구조

## 개발동향

`trends.html`의 핵심 영역입니다. 우주기관, 민간 우주기업, 발사체, 위성, 탐사 프로젝트, 우주정책 이슈를 사실 확인 중심으로 다룹니다.

주요 데이터는 `data/trends.js`에 정리하며, 관리자 콘솔에서 발행한 실시간 뉴스는 `data/published.json`을 통해 표시합니다.

## 지식허브

`knowledge.html`의 천문학 입문 공간입니다. 기관형 분류보다 사용자의 질문을 따라 들어가는 지식 지도 형태를 지향합니다.

대분류는 다음 8개를 기준으로 운영합니다.

- 하늘과 관측
- 태양계 여행
- 별의 삶과 죽음
- 은하와 우주
- 망원경과 관측기술
- 우주탐사와 우주개발
- 천문학의 역사와 사람들
- 천문학 기초 물리

실제 글이 없는 항목은 `준비 중` 상태로 표시하고, 클릭 시 placeholder 안내가 나오도록 유지합니다.

## 우주와 우리 삶

`cosmos-life.html`의 에세이형 공간입니다. 우주 현상, 우주 프로젝트, SF/다큐, 우주 윤리, 천문학적 관점을 인간의 삶과 연결합니다.

하위 코너는 다음을 기준으로 운영합니다.

- 하루 한 번, 우주가 건네는 말
- 우주 프로젝트 속 인간 이야기
- SF와 우주 인문학
- 우주 윤리와 문명 이야기
- 나의 우주 공부 노트

## 관측환경정보 서비스 예정

향후 사용자의 위치 또는 선택 지역을 기반으로 구름, 달 위상, 광해, 관측 추천 시간을 제공하는 서비스로 확장할 수 있습니다.

초기에는 정적 안내 페이지와 관측 체크리스트로 시작하고, 이후 날씨/천문 API 연결을 검토합니다.

## 위성 위치 조회 서비스 예정

향후 주요 인공위성, ISS, 스타링크 등 하늘에서 볼 수 있는 위성의 위치와 통과 시간을 안내하는 서비스로 확장할 수 있습니다.

초기에는 교육용 설명과 대표 위성 목록을 제공하고, 이후 TLE 데이터 또는 외부 위성 추적 API 연결을 검토합니다.
